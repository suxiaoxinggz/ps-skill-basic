# 交付前检查清单

> 按顺序走一遍。**A 组是硬门槛**，任何一项不过就不要交付。

## A. 硬门槛

- [ ] `lint` + `typecheck` + `build` 全绿（本仓库 `npm run check` 一次跑完）。
- [ ] **无横向溢出**：`document.documentElement.scrollWidth <= window.innerWidth`
      （1440 / 768 / 375 三个视口各测一次）。
- [ ] reduced-motion 下页面**完整可读**：开启系统"减弱动态效果"后刷新，
      所有内容可见、无空白区、悬浮条与轮播仍可用。
- [ ] 键盘可达：Tab 能走到导航、CTA、输入条；焦点环可见（不要 `outline: none` 了事）。

## B. 配色纪律

- [ ] 全站 accent 只出现**一个**颜色；没有被大面积铺底。
- [ ] "发光"效果全站只出现一次（CTA）。
- [ ] 底色不是纯黑/纯灰（保留 ≤0.01 的 chroma 偏移）。
- [ ] 暗卡没加阴影（只用 `border-white/10`）；白纸卡加了 `.at-lift`。
- [ ] logo 墙全部 `grayscale`；案例卡里也是。
- [ ] 没有彩虹渐变、没有色相差 <30° 的近似色搭配。

## C. 排版

- [ ] 字体角色没混用：h1/h2 是 display、标题内强调是衬线、元数据是 mono。
- [ ] 中文没加载 webfont（走系统回退）。
- [ ] h2 有负字距（`-0.9px` 量级）；eyebrow 有正字距（`0.08em` 量级）。
- [ ] 长文案不会被截断得莫名其妙（检查 `line-clamp` 的边界情况）。

## D. 叙事结构

- [ ] 10 幕齐全且顺序正确（尤其第 5 幕演示在社会证明之后）。
- [ ] 产品演示幕能证明"输入 → 处理 → 产出"的完整链路，不是纯视频。
- [ ] 演示面板里的数字/文案**能自圆其说**（`进度 3/7 · Panel 6` 和显示内容一致）。
- [ ] 全局悬浮条在 CTA 区已淡出，没有两个输入条同时出现。
- [ ] Hero 漂浮卡没有压住 h1。

## E. 动效

- [ ] 进场 reveal 播一次即停（`unobserve`）。
- [ ] hover 只做 opacity / scale(1.05) / 箭头位移——没有 bounce。
- [ ] 打字机速度在 68/24ms 量级，不是闪电式。
- [ ] 所有动画都有 reduced-motion 分支。

## F. 性能

- [ ] Hero 视频 `muted + loop + playsInline + poster`；poster 是 LCP 图。
- [ ] 视频体积 < 5MB（超过就转码或换更短的）。
- [ ] 图片走 `next/image` 或已压缩；首屏没有 > 500KB 的单图。
- [ ] client component ≤ 4 个（ScrollReveal / 打字机 / 产品演示 / 轮播）。
- [ ] 没有在 effect 里同步 setState。

## G. 响应式

- [ ] 375 / 768 / 1440 三个宽度都看过，不是"能显示"而是"好看"。
- [ ] 漂浮卡、网格背景、透视倾斜在 `< md` 已关闭或简化。
- [ ] 滚动步进轨道在小屏降级为普通文档流 + 进度条。
- [ ] 导航在小屏收进汉堡；CTA 按钮不挤。

## H. 克隆任务额外项

- [ ] 文案与源站一致（逐 section 比对 innerText，不是凭印象）。
- [ ] 资产用的是源站原图（不是占位图、不是重新生成的近似图）。
- [ ] 交付说明里**主动列出残留差异**与判定理由（见 error-log #9）。
